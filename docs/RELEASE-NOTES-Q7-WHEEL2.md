# HHQ Q7 Android 6 — FYT 方向盘切歌适配（wheel2）

- 为 FYT6025 / Android 6 增加厂商播放器按键接收，补上标准 MediaSession 收不到按键时的入口。
- 将明确的上一首／下一首命令发送给 iPhone，并防止同一次按键从多个入口重复触发。
- 会话结束时注销接收；增加服务连接、按键编号和发送结果日志。
- 保留 wheel1 的 Android 6 媒体按键注册修复，以及此前的音频和热点恢复修复。

版本：`0.2.20-android6-q7-wheel2-slim`（versionCode 45）。沿用原包名和签名，可直接覆盖安装。
无需为此开启无障碍服务。连接 CarPlay 并播放音乐后，测试方向盘上一首、下一首。
