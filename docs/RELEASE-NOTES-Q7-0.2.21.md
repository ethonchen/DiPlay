# HHQ Q7 Android 6 — DiPlay 0.2.21 上游更新

版本：`0.2.21-android6-q7-upstream1-slim`（versionCode 48）。
包名沿用 `com.shihab.diplay.hudtest`，沿用 Q7 原测试签名，可覆盖安装并保留设置。

## 本次更新

从 shihabal3amri/DiPlay 合入 0.2.21（`6d3b8a8ce927cb4b115b8c3881f17619433e93b1`），包含 31 个上游 PR 的功能与修复。

- 修复 0.2.20 的音乐积压和切歌/暂停延迟，短时无线抖动仍保留缓冲。
- 通话或短暂失去音频焦点后，在 iPhone 恢复播放时重新请求焦点。
- 软件 Opus 编码失败时丢弃单帧，避免旧安卓上使用麦克风导致整个应用退出。
- 增加有线启动超时恢复、USB 重枚举等待期限，避免重试断开已恢复的连接。
- 改善无线失败和权限提示、蓝牙启动等待、特殊热点接口识别与 USB 保存后重连。
- 增加临时系统栏、黑色圆角、双击 Siri、播放/暂停键映射、桌面悬浮球及意大利语。
- 合入 BYD 专用仪表、分屏和氛围灯更新；这些功能依赖对应车辆，Q7 无需开启。

## Q7 合并处理

- 保留 Android 6 / API 23、ARMv7、v1 签名和瘦身构建；不跟随上游改成 API 24 最低版本。
- 完整保留 2026-10-17 实车确认的 wheel4 方向盘接收、FYT 焦点及防重复处理。
- 保留 2.4 GHz 能力过滤、Q7 热点恢复及既有配置。
- 合并上游导航 PCM 衰减与本分支导航播报期间压低音乐，两者作用不同，继续共同生效。
- 新增异步支持接口沿用 API 23 可用的 retrofuture；热点新 API 继续按安卓版本隔离。
- 新可选功能保持上游默认关闭，不会自动改写车机热点。

## 发布验证

发布任务要求完整单元测试、API 兼容性检查、Lint、源码构建、Q7 优化构建、API 23/ARMv7/原签名验证、Android 6 模拟器安装启动、运行时认证探针及媒体按键接收检查全部通过后才发布 APK。

本更新尚未经 Q7 实车验证；wheel4 按键路径沿用实车验证实现，但新增上游功能仍需实际使用反馈。
