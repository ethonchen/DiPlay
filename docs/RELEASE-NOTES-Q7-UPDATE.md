# HHQ Q7 Android 6 — 上游 0.2.22 更新

版本 `0.2.22-android6-q7-upstream1-slim`，versionCode **52**。

合入上游 `shihabal3amri/DiPlay` 的 0.2.22 后续主干，包含：

- AirPlay 画面、iAP、设置、事件和时钟通道校验控制连接的对端，拒绝其他来源的数据。
- 默认 PCM 麦克风音频分包适配网络 MTU，修正部分 USB 语音录制静音问题。
- 增加土耳其语及相关文档更新。
- 保留 Android 6 / API 23、ARMv7、Q7 热点恢复、导航时压低音乐、方向盘切歌以及应用内更新和下载代理切换。

安装包使用与 update1、update2-fix1 相同的包名和签名，允许覆盖安装并保留设置。建议从 update2-fix1 的 **设置 → 关于 → 检查更新** 更新。车机需要能访问互联网。

如果当前仍是 update1 或最初的 update2，标准 Android 6 安装器可能无法通过应用内安装按钮打开 APK。若下载并校验成功后安装按钮报错，可在车机文件管理器中打开应用提示的已下载文件并覆盖安装，无需卸载。

新增上游改动尚待 HHQ Q7 实车验证；模拟器测试不能替代真实无线连接、声音和方向盘测试。
